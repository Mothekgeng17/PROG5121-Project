### 📝 Project Description
A Java console application for user registration, login, and storing messages.

### Features Implemented
- **Part 1:** User Registration & Login with validation
- **Part 2:** Send messages, generate message hash, display sent messages
- **Part 3:** Stored Messages using Arrays, search, delete, and generate report

### 💻 How to Run
1. Open project in NetBeans
2. Run `Programming1A_POE.java`
3. Register a new user
4. Login and test the menu
